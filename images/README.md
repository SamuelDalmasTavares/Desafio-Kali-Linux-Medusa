# Evidências

É aqui que ficam os prints dos testes. Fui guardando as telas de cada etapa pra
comprovar que o lab rodou de verdade.

Prints que pretendo colocar:

- `rede_virtualbox.png` – a rede host-only configurada no VirtualBox
- `nmap_full.png` – o resultado do reconhecimento com Nmap
- `ftp_sucesso.png` – o "ACCOUNT FOUND" do FTP e o login funcionando
- `dvwa_config.png` – o DVWA no nível Low
- `dvwa_sucesso.png` – a senha encontrada no formulário web
- `smb_enum.png` – a enumeração de usuários com enum4linux
- `smb_sucesso.png` – o resultado do password spraying no SMB

Os arquivos `*_resultado.txt` são gerados pelos próprios scripts (opção `-O` do
Medusa).
